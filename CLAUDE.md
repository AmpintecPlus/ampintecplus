# Claude Code and Antigravity Cowork Test Project

This project is a sandbox for testing collaborative workflows between **Claude Code** and **Antigravity**.

## Commands
- Run tests: `python3 -m unittest discover -s test`
- Format code: `black .` (or equivalent python formatter if installed)

## Guidelines
- Write tests for new functions.
- Follow PEP 8 guidelines.
- Always commit changes with descriptive messages.
